# AI SOC assurance: independent benchmarks, failure modes, residency, model risk, decision audit and product evaluation

Vendor-neutral assurance for AI-assisted security operations centres. The first system under test is
[Jagadish-azure-ai-soc](https://github.com/jagadishmazure-jpg/Jagadish-azure-ai-soc), driven through an
adapter interface so any other product can be plugged in the same way.

The full documentation is being written in this repository; see `docs/` as it lands.
